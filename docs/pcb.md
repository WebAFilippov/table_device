# Плата-носитель «Стол» — проект под ЛУТ (домашнее изготовление)

Односторонняя плата, FR-4 1.5 мм, **110 × 85 мм**. На плате размещаются
только модули (DevKitC-1, дисплей, BTS7960) и обвязка. Травим дома ЛУТ.

> ВАЖНО: перед переносом на плату сверь штангенциркулем:
> 1) расстояние между рядами пинов DevKitC (в плане взято ~22 мм);
> 2) порядок пинов разъёмов дисплея и BTS7960 (по маркировке модулей).

- **Земля-звезда**: толстая GND-шина (≥2 мм) по нижнему краю платы и левой колонке;

## 4. Правила разводки под ЛУТ

| Параметр | Значение |
|---|---|
| Ширина сигнальных дорожек | **0.6 мм** (меньше нельзя — подтрав) |
| Зазор между дорожками | **0.6 мм** |
| Силовые дорожки (24В, мотор) | **2–3 мм** или заливка |
| Площадки | Ø2.0 мм, отверстия Ø0.9–1.0 мм |
| Перемычки | 0.6 мм проводом сверху, отвести 2–4 места (в разрывах дорожек) |
| Печать | **зеркальная**, на глянцевой бумаге, тонер по максимуму |

Порядок работ: зачистить медь нулёвкой → обезжирить ацетоном → прогладить
утюгом (макс. темп., 1.5–2 мин, без сдвигов) → отмочить бумагу → ретушь
маркером → травить (FeCl3, ~40°C, 15–30 мин, покачивать) → смыть тонер →
сверлить → залудить → паять. Перчатки, очки, проветривание.

**Контроль перед травлением:** прозвонить тестером не нужно (медь сплошная) —
проверь визуально, что все пары площадок, которые НЕ должны соединяться,
разделены промежутками ≥0.6 мм, и что у каждой цепи есть связь.
