# Стол с регулировкой высоты — ESP32-S3

Приборная часть проекта: ESP32-S3 (N16R8) + дисплей 4" ST7796/FT6336U + драйвер BTS7960 + мотор 24В (червячный редуктор, энкодер A/B).

---

## 1. Распиновка

### Дисплей (SPI) и тач (I2C)

| Дисплей | ESP32-S3 |
|---|---|
| SDI (MOSI) | GPIO 11 |
| SCK | GPIO 12 |
| SDO (MISO) | GPIO 13 (можно не подключать) |
| LCD_CS | GPIO 10 |
| LCD_RS (DC) | GPIO 4 |
| LCD_RST | GPIO 5 |
| LED | GPIO 7 (ШИМ подсветки) |
| VCC | 3.3V |
| GND | GND |
| CTP_SDA | GPIO 8 |
| CTP_SCL | GPIO 9 |
| CTP_RST | GPIO 6 |
| CTP_INT | GPIO 14 (не используется — поллинг) |
| SD_CS | не используется (подтяни 10к к 3.3В, если есть) |

### Энкодер

| Провод | Куда |
|---|---|
| Белый (+5В) | пин 5V платы |
| Чёрный (−5В/GND) | GND |
| Зелёный (A) | GPIO 15 **через делитель** |
| Синий (B) | GPIO 16 **через делитель** |

**Делитель обязателен** (выходы энкодера до ~4.8 В, GPIO держат до ~3.6 В):

```
энкодер A ──[1 кОм]──┬── GPIO15
                     │
                   [1.5 кОм]
                     │
                    GND
```

То же самое для B на GPIO16.

### Драйвер BTS7960

| Драйвер | Куда |
|---|---|
| VCC | +24В от БП |
| GND | −24В от БП **и** GND платы (общая земля) |
| B+ | мотор: красный (24В+) |
| B− | мотор: чёрный (24В−) |
| RPWM | GPIO 38 |
| LPWM | GPIO 39 |
| R_EN | GPIO 40 |
| L_EN | GPIO 41 |
| R_IS | [1 кОм] → GND, средняя точка → GPIO 1 |
| L_IS | [1 кОм] → GND, средняя точка → GPIO 2 |

- Если на модуле есть пиновый «5V» — это обычно **выход** встроенного стабилизатора, ничего туда не подключай.
- **Банка 470–2200 мкФ × 50В** прямо на клеммах VCC/GND драйвера — обязательно.
- GPIO 21 — резерв (сюда вернём E-stop).

### Питание

- Плату ESP32 питай от **USB-зарядки на 2А+** (подсветка + PSRAM едят ток).
- БП 24В — только на драйвер.
- Минус БП 24В, GND драйвера и GND платы — **в одну точку**.

## 2. Сборка прошивок (PlatformIO)

Проект настроен на плату `esp32-s3-devkitc-1-n16r8v` (16 МБ flash + 8 МБ OPI PSRAM).

Четыре окружения:

| Окружение | Что собирает |
|---|---|
| `test01` | дисплей + тач |
| `test02` | энкодер |
| `test03` | мотор |
| `firmware` | боевая прошивка (`src/main.cpp`, пока заглушка) |

Порядок: выбрать окружение (нижняя панель VS Code) → **Build** → **Upload** → **Serial Monitor** (115200).

Зависимости (`TFT_eSPI`, `ESP32Encoder`) скачаются сами при первой сборке.
Если при Upload не находится порт — выбери COM-порт UART-интерфейса платы (тот, где работал Serial0).

## 3. Тест 1 — дисплей и тач

**Ожидаем:** экран заливается, надпись «Display OK: ST7796», цветные полосы; в мониторе «Touch: vendor=… chip=…» и «Touch: I2C OK». Ведёшь пальцем — рисуется белый кружок, в мониторе координаты.

**Если что-то не так:**
- «NO I2C» на экране → проверь SDA/SCL (8/9), питание тача 3.3В, CTP_RST (6), адрес 0x38.
- Кружок не под пальцем / зеркальный → в `main.cpp` включи другой вариант пересчёта координат (там закомментированы готовые строки).
- Нет подсветки → проверь LED (GPIO7); как временная проверка — подать на LED 3.3В напрямую.
- Картинка в негативе / цвета BGR → добавить в `platformio.ini` флаг `-DTFT_INVERSION_ON` (или `-DTFT_RGB_ORDER=TFT_BGR`).
- Артефакты/мусор на экране → снизить `SPI_FREQUENCY` до 27000000.

## 4. Тест 2 — энкодер

Мотор **обесточен** (24В отключено), энкодер питается 5В.

1. Прошей `test02`, открой монитор.
2. Крути **вал мотора** вручную — счётчик меняется.
3. Сделай ровно **1 оборот вала мотора** → `показание / 4 = PPR` энкодера.
4. Сделай ровно **1 оборот выходного вала** → `показание / 4 = PPR × передаточное число` (заодно узнаем передаточное).
5. Команда `r` — сброс счётчика.

Пришли результат: PPR и счёт за оборот выходного вала.

**Если счётчик не меняется:** проверь делители (сигнал на GPIO должен быть ~2.9 В в «1» и ~0.4 В в «0»), питание энкодера 5В, общую землю.

## 5. Тест 3 — мотор

Мотор **установлен в механизм**, концы хода свободны. Прошей `test03`, открой монитор.

Команды: `f`/`r` — направление, `1..9` — скорость, `s` — стоп, `i` — показать токи.

**Порядок:**
1. `1` → короткий импульс. Убедись, что механика едет плавно, определи направление («вверх/вниз»).
2. Подними до `3`–`4` — проверь плавность.
3. Смотри токи в мониторе:

| Ситуация | Ожидаемый raw ADC (R_IS/L_IS) | Ток |
|---|---|---|
| Холостой ход | ~150 | ~1 А |
| Номинал (паспорт) | ~600 | ~3.8 А |
| Наш будущий порог | ~700 | ~4.5 А |

`raw` и амперы — оценка (±20%), откалибруем позже по амперметру.

**Стоп сразу, если:** ток >5 А, мотор дёргается, слышен хруст, дым, запах. НЕ упирайся в концы хода в этом тесте.
